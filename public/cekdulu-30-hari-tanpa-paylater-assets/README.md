# CekDulu — 30 Hari Tanpa PayLater / Asset Pack

Asset pack ini disiapkan sebagai referensi visual untuk implementasi UI oleh OpenCode.

## Struktur
- `illustrations/` — ilustrasi utama challenge
- `icons/` — ikon kecil reusable
- `reference/ui-flow-reference.png` — mockup alur UI mobile yang menjadi referensi
- `reference/cekdulu-brand-reference.png` — referensi visual/brand CekDulu
- `docs/usage.md` — arahan penggunaan

## Catatan implementasi
Untuk MVP, OpenCode tidak perlu membuat asset baru. Jika ada kebutuhan visual yang belum tersedia,
gunakan placeholder sederhana dengan ukuran/aspect ratio yang sama.

Asset SVG sengaja dibuat ringan agar cocok untuk static-first/mobile-first.
